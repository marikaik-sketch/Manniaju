# Topu Puhkemaja

**Kasuta seda kausta alati, kui teed Topu turundust** — Facebooki postitused, kodulehe tekstid, pakkumised külastajatele. See on Topu hääl, mitte BDA oma. Üldised kirjutamise reeglid tulevad failist [`01-mina/stiil-ja-toon.md`](../../01-mina/stiil-ja-toon.md).

## Mis see on

- **Topu Puhkemaja** — meie oma majutusasutus. Koduleht: [www.topu.ee](https://www.topu.ee)
- **Minu roll:** teen Topu turundust.
- **Maja, toad, söök, tegevused, kodukord:** vt [`maja.md`](maja.md).
- **Kirjad külalistele** (vastus päringule, kiri enne tulekut, ülevaade, lisakohad): vt [`kirjad.md`](kirjad.md).
- **Facebooki hääl ja näited:** vt [`facebook.md`](facebook.md).
- **Hinnad ja broneerimise tingimused:** vt [`hinnad.md`](hinnad.md).
- **Broneeringud** tulevad kalendrisse „Topu Puhkemaja Bronnid" (vt [`skillid/hommikune-briif`](../../skillid/hommikune-briif/SKILL.md)).

## Kes meil käivad

2026. aasta suvel: perekonnad, suguvõsad, kunstilaagrid suurtele ja väikestele. Varasemates FB postitustes ka sõpruskonnad ja klassikokkutulekud (osa käib igal aastal). Hinnakirjas on eraldi soodustus lastelaagritele.

## Kus mis on

- **Siin kaustas:** püsiv teadmine — kellele Topu on, mis sõnumid töötavad, Topu hääl ja reeglid.
- **Agendikonto Drive'is, kaust `Topu`:** toormaterjal — vanad postitused, pildid, külaliste andmed. Külaliste nimed ja kontaktid ajju ei tule.
